# Motion-capture позы

Файлы `*.json` — производные данные для рига, полученные скриптом `scripts/convert-mocap.mjs` 14 ноября 2026 года. Исходные FBX в репозиторий не входят.

## Источник

- `Soccer Game Pack.zip` (Mixamo, 54 клипа без меша) и `Dribble.fbx` — предоставлены пользователем, лежат в его `Downloads`. По описанию старого проекта (`games/soccer-duel/public/assets/player/NOTICE.txt`) персонаж и клипы — Mixamo Remy.
- Скелет клипов и `assets/player/player.glb` один и тот же (67 костей), поэтому позы переносятся без подгонки.
- Клипы из старой папки `games/soccer-duel` не копировались: импорт выполнен заново из исходных FBX.

Это внутренние производные данные для игры, не самостоятельный набор ассетов. Перед публикацией подтвердить условия Mixamo для коммерческого использования и сохранить сведения в документации релиза. Данные Pro Evolution Soccer 6 не используются и использоваться не должны: это закрытые ассеты Konami.

## Что импортировано

| Файл | Исходник | Использование |
|---|---|---|
| `idle.json` | offensive idle | стойка |
| `jog-forward.json`, `jog-backward.json`, `jog-left.json`, `jog-right.json` | jog forward / backward / strafe | корпус, руки, голова и таз в беге |
| `kick.json` | kick soccerball | удар с места (для другой ноги — зеркально) |
| `strike-jog.json` | strike foward jog | удар с хода |
| `receive.json` | receive soccerball | жест приёма |
| `dribble.json`, `knee.json`, `header.json` | Dribble, kneeing, header | сконвертированы, в игре пока не подключены |

`import-report.json` — длительности, ход таза, моменты постановки стоп и контакта для каждого клипа.

## Формат

Для каждой кости хранится мировой поворот относительно T-позы в осях «Y вверх, персонаж смотрит на +Z»; для таза — положение в долях его высоты в T-позе. 30 кадров/с. У зацикленных клипов убран линейный снос таза.

## Повторить импорт

```text
node scripts/convert-mocap.mjs "<распакованный Soccer Game Pack>" "<путь к Dribble.fbx>"
```

Ноги в игре ставятся в точки стоп из симуляции (IK), а не проигрываются из клипа: контакт стопы с мячом и покрытием определяет симуляция.
