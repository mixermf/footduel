# Motion-capture позы

Файлы `*.json` — производные данные для рига, полученные скриптом `scripts/convert-mocap.mjs` 14 ноября 2026 года. Исходные FBX в репозиторий не входят.

## Источник

- `Soccer Game Pack.zip` (Mixamo, 54 клипа без меша) и `Dribble.fbx` — предоставлены пользователем, лежат в его `Downloads`. По описанию старого проекта (`games/soccer-duel/public/assets/player/NOTICE.txt`) персонаж и клипы — Mixamo Remy.
- Скелет клипов и `assets/player/player.glb` один и тот же (67 костей), поэтому позы переносятся без подгонки.
- Клипы из старой папки `games/soccer-duel` не копировались: импорт выполнен заново из исходных FBX.

Это внутренние производные данные для игры, не самостоятельный набор ассетов. Перед публикацией подтвердить условия Mixamo для коммерческого использования и сохранить сведения в документации релиза. Данные Pro Evolution Soccer 6 не используются и использоваться не должны: это закрытые ассеты Konami.

## Что импортировано

| Файл | Исходник | Использование |
|---|---|---|
| `idle.json` | offensive idle | стойка |
| `jog-forward.json`, `jog-backward.json`, `jog-left.json`, `jog-right.json` | jog forward / backward / strafe | корпус, руки, голова и таз в беге |
| `kick.json` | kick soccerball | удар с места (для другой ноги — зеркально) |
| `strike-jog.json` | strike foward jog | удар с хода |
| `receive.json` | receive soccerball | жест приёма |
| `dribble.json`, `knee.json`, `header.json` | Dribble, kneeing, header | сконвертированы, в игре пока не подключены |

`import-report.json` — длительности, ход таза, моменты постановки стоп и контакта для каждого клипа.

## Набор Mocap Pack 05 Soccer

Файлы `pack-*.json` получены скриптом `scripts/convert-soccer-pack.mjs` 15 ноября 2026 года из архива `Mocap_Pack_05_Soccer.zip`, предоставленного пользователем (лежит в его `Downloads`). В архиве 21 клип в трёх вариантах скелета; импорт идёт из `mocap/Rokoko_Default`. Исходные FBX в репозиторий не входят. Перед публикацией подтвердить условия лицензии набора для коммерческого использования.

| Файл | Исходник, окно | Использование |
|---|---|---|
| `pack-kick-side.json` | 08_Side_Foot_Kick, 0,55–2,0 с, правая, контакт 0,84 с | удар с места при заряде ниже 0,55 |
| `pack-kick-power.json` | 09_Power_Kick, 1,5–3,15 с, левая, контакт 1,08 с | удар с места при заряде от 0,55 |
| `pack-guard.json` | 18_Defending_01, 0,5–4,4 с, зациклен | верх тела в защитной стойке |
| `pack-juggle.json` | 04_Juggling_01, 1,6–12,0 с, зациклен | верх тела в чеканке |
| `pack-celebrate.json` | 13_Goal_Celebration_02, 0,2–3,3 с | руки и корпус забившего после гола |

Скелет Rokoko стоит в той же T-позе, что Mixamo, поэтому поворот переносится по именам костей (грудь — с `Spine4`); подгонка по направлениям костей не делалась. Первый и последний кадры каждого файла набора — T-поза, поэтому берётся окно. Клип доворачивается так, чтобы опорное направление (у ударов — полёт бьющей стопы в момент контакта) смотрело на +Z; ход таза по горизонтали отброшен. `import-report-pack.json` — окна, контакты и высота таза.

У клипов ударов есть поле `feet`: голеностопы относительно тазобедренного сустава своей ноги в долях длины ноги, по шесть чисел на кадр (левая, правая). По нему риг ведёт бьющую ногу: траектория, направление колена и разворот стопы — из клипа, а симуляция подтягивает стопу к точке контакта с мячом в пределах `adapt.kickReach` (см. `PlayerRig.adapt`). Опорная нога и все остальные движения ног по-прежнему ставятся в точки стоп из симуляции.

В наборе нет ходьбы и бега. Не импортированы: дриблинг (три дубля с разворотами, не циклы), пенальти, вбрасывание, вратарь, карточки, остальные чеканки и празднования. Обзор набора перед импортом: `node scripts/inspect-fbx.mjs "<папка>"`, покадровый профиль клипа — с ключом `--timeline <файл>`.

```text
node scripts/convert-soccer-pack.mjs "<распакованная папка mocap/Rokoko_Default>"
```

## Формат

Для каждой кости хранится мировой поворот относительно T-позы в осях «Y вверх, персонаж смотрит на +Z»; для таза — положение в долях его высоты в T-позе. 30 кадров/с. У зацикленных клипов убран линейный снос таза.

## Повторить импорт

```text
node scripts/convert-mocap.mjs "<распакованный Soccer Game Pack>" "<путь к Dribble.fbx>"
```

Ноги в игре ставятся в точки стоп из симуляции (IK): контакт стопы с мячом и покрытием определяет симуляция. Исключение — мах ноги в обычном беге: без мяча маховая нога идёт в основном по клипу бега (траектория голеностопа, направление колена, разворот стопы), с мячом — в основном по симуляции; веса — `legFree` и `legBall` в `PlayerRig.adapt`. Опорная стопа всегда стоит там, где её поставила симуляция. Клип бега читается с опережением фазы `clipLead`: без него таз был ниже всего в момент отрыва стопы, а не в середине опоры.

Клипа ходьбы и клипа спринта в наборах нет: шаг целиком процедурный, спринт — клип трусцы с процедурными добавками.
